# 「同伴关系」方向总览

> 写于 9/17，设备（录音豆，本赛道指定的可穿戴录音硬件）9/19 到。标【推断】的是我们自己的推理，没有数据支撑。

这是球球从「防霸凌」延伸出的一条方向线：不录内容，只看两人谈话的「形状」（谁说了多久、怎么轮流），并和当事人自己的感觉对照。**主线仍是「听诊器」（让录音豆去听机器、不听人，见[打法报告](../打法报告.md)）；这条线是预赛文档和路演的亮点、决赛的备选，不替换主线。**

一句话结论：儿童版合规判死；成人版「两人一起看、先猜后看」能做，但价值前提还没有数据。去留靠两次检验定：设备到货后的真机对比（9/21 前），和一次用手机就能做、不需要设备的预跑（9/24 前出结论，见第 5 节）。

## 1. 来龙去脉

每一步都是上一步被数据否掉后走出来的，可当官方六个评分维度里「产品创新」那一维的素材。

**① 起点：防霸凌求助按钮（团队 9/10 提出）。** 两轮调研后降为备选（[防霸凌第二轮核查-触发时机](../防霸凌第二轮核查-触发时机.md)），卡在触发时机：事中按不了（单次事件平均 38 秒，被按住时可能强直不动，当面按亮灯设备等于递给对方）；事前例行开启只能覆盖约 11–19% 的受害者（这个比例由几个比例相乘估出，其中一个没有数据）；事后标记用不着录音硬件。更硬的一道是官方红线：「所有场景必须确保被录人知情，禁止偷录、窃听」（9/9 直播纪要）。球球提出过「录音不需要法律效力，老师和家长看见就够」，这一点是对的，但红线管的是知不知情，不是法律效力；而隐蔽性恰恰是防霸凌录音的价值所在。另一个数字指向了别处：44% 的受害者谁都不告诉（Blomqvist 2019）。

**② 球球的第一跳：价值不在取证，在「让大人看见」。** 瓶颈是没人知道，不是没有证据。「看见」不需要录到内容，只需要关系的形状：谁跟谁说话、各说多久。由此想到做一个**同伴关系**系统。

**③ 球球的第二个想法：像小天才电话手表那样的儿童录音豆。** 做一个交友系统：今天跟谁说了话、亲密度，还能从说话方式识别故意的 PUA 式打压（精神操控、贬低）。

核实结论：**合规判死。** 法律上，PIPL（《个人信息保护法》）第 13 条列的合法处理依据里，没有欧盟 GDPR 那种「正当利益」；未成年人信息和声纹都是敏感个人信息，双重叠加；长沙望城案（最高检 2023 年典型案例）里家长点了同意，照样被认定为过度收集。技术上，在儿童可穿戴录音里判断「有没有其他儿童在说话」，F-score（兼顾查准和查全的综合分，满分 100%）只有 33%，9/19 的真机测试推翻不了。但也确认了一个真空：LENA（最常用的儿童全天录音与自动分析系统）二十年来，按定义就从不计算孩子与孩子之间的对话。

**④ 收窄：成年人、两个人、双方自愿、一起看结果。** 推荐形态叫「形状」：带教的人（mentor）和被带的人（mentee）谈完，一起看各自说了多久，和各自事先的猜测并排对照。我们对三个候选形态（「形状」「自己听自己」「访谈自检」）按官方六个评分维度做了两轮内部审阅，每维 1–3 分、满分 18，三个都只在 9–11 分。收窄的代价是空白没了：Gong（做销售通话分析的公司，早就在统计谈话双方各说多少）等早有先例。

**⑤ 球球的第三个想法：「你以为的我、我以为的你、我以为你以为的我」。** 这正对应 Laing 1966 提出的「元视角」（我以为你怎么看我）。我们把它做成「对话元知觉仪表」：说话占比交给录音豆测，对方怎么看交给对方本人打分。

核实结论：站得住的是 liking gap（聊完后普遍低估对方有多喜欢自己；样本 N = 1,835，效应量 d = .70，属中到大），但这一层用问卷就能测，不需要硬件；需要硬件的那层（人对自己说话占比的估计偏差）证据薄弱。按官方六个评分维度自评，六维里有五维只到最低的「基础」档。

**⑥ 球球的第四个想法：AI 时代技术被模型吞噬，人际关系越来越重要。** 核实结论：当成结论讲，证据太薄；Deming（经济学家，研究社交技能在劳动力市场的回报）的数据止于 2012 年，只能用降级版：「上一轮自动化的规律，我们赌这一轮也成立」。最好的硬数字其实是 Talk Meter（给辅导老师显示师生各说了多久的工具）的随机对照实验，测法和我们接近。

## 5. 如果继续：先做一次不需要设备的预跑

用手机就能做，不等 9/19。

- **样本**：队外 10 对成年人（队员会被假设带偏），当场抽话题聊 2–3 分钟；当面同意，标注完删录音。
- **录音**：手机一部贴在其中一人（记为 A）胸前模拟佩戴，一部放桌子中间【推断】。
- **每人 3 题**：刚才你说话占几成（0–100）；聊得愉快吗（1–7）；你猜对方觉得愉快吗（1–7）。
- **标注**：用 Audacity（免费音频编辑软件）的标签功能人工标出每人的说话段，作为真值；再跑自动分段（语音检测、两人区分、丢掉短于 1 秒的段）。

一次采集回答三个问题：

| # | 问题 | 停止线 |
|---|---|---|
| 1 | 人估自己说了多少，偏得多吗（「先猜后看」的前提） | 自估与真值之差（取绝对值）的中位数小于 10 个百分点 → 人其实估得挺准，停 |
| 2 | 自动测量比人估得准吗；胸前比桌上准吗 | 自动测量的误差不比人的自估误差小 → 录音豆给不出人猜不到的信息，只剩计时器的作用，换方向 |
| 3 | 双方是否都低估对方打分；占比偏离 50:50 和愉快打分有没有关系 | 不设，样本小，只当试点报告 |

约 2–3 人日，瓶颈是招募【推断】。9/24 前出结论；若触发停止线，预赛文档里这条线只留一段「已验证、已否定」。

有三件事手机替代不了，仍要 9/19 设备到货后测：真机佩戴是否比桌上准；`isMark`（双击打标后，实时音频分片里带的标记位）能否及时到达；`deleteFiles` 删除后回读是否为 0。9/21 前若桌上手机的误差并不明显大于豆子，同样停。
