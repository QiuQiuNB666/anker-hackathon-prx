## 高履历自述的可验证性：一则方法论

同场有两位选手公开了非常强的战绩自述。经公开网页交叉核查后，多数条目**无法对应到任何已发布的获奖名单或报道**。

**这不等于虚假**——黑客松获奖项目不被媒体点名是常态，社区逆向工作也几乎不会进正规新闻。但它意味着：这些战绩应当作为**自述**看待，而不是既定事实，更不该成为你调整自身策略的依据。

典型的对不上模式（均已脱敏，只保留结构）：

| 自述类型 | 核查结果 |
|---|---|
| 某黑客松某赛道金奖 + 具体项目名 | 赛事真实存在，但公开报道的获奖项目名单里**没有该项目** |
| 某大赛三等奖 + 具体作品名 | 赛事与赞助商硬件均真实，公开 gallery 里的同类作品**是另一个名字** |
| 某交易所黑客松特别奖 + 项目名 | 该系列黑客松真实举办，公开获奖名单里**无此项目** |
| 国际学术竞赛金奖 | 赛事真实，公开名单**未出现该姓名** |
| 某加速器 / 创业营成员 | 机构真实且方向吻合，但**学员名单本就不公开点名**，无法证伪也无法证实 |
| 前某公司某内部计划成员 | 该内部计划确实存在且公开报道过，**但未点名个人** |

其中只有一条值得真正警惕：**有人自述逆向过飞书录音豆、钉钉 A1、Plaud 的通信协议**。这三款设备都是 2025–2026 年公开在售的 AI 录音硬件，被社区逆向并不稀奇，细节无法证实——但若属实，此人是这条赛道技术上最需要重视的对手。他截至 9/10 仍未进入组队大厅。

## 对 PRX 的含义

1. **智能录音这 4 支，没有一支的方案是锁死的。** T-035 方向明确但缺硬件人；T-043 撞可验证性的墙；T-045 和 T-047 连方向都没定。**这条赛道现在还是空的，先把方案钉死的人占优。**
2. **四支全在做「听人说话」**，全部要处理主办方那条「所有场景必须确保被录人知情，禁止偷录窃听」的红线。听机器的方向天然在线外。
3. 多数队长使用平台匿名号，公开足迹本就很浅。竞争情报的真正价值在**方向分布**，不在人。
